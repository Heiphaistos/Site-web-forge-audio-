Installer le .deb (Debian, Ubuntu, Mint)

  1. Ouvrez un terminal dans le dossier Téléchargements : dans le gestionnaire de fichiers, clic droit dans le dossier → Ouvrir dans un terminal. Ou ouvrez un terminal (Ctrl + Alt + T sur Ubuntu et Mint) et tapez cd ~/Téléchargements (ou cd ~/Downloads si votre système est en anglais).
  2. Installez le paquet en tapant (ou en collant avec Ctrl + Maj + V) : 
    sudo apt install ./ForgeAudio-*-linux-amd64.deb

    Le ./ devant le nom est indispensable : il dit à apt d'installer ce fichier-là plutôt que de chercher un paquet en ligne. sudo demande votre mot de passe ; rien ne s'affiche pendant que vous le tapez, c'est normal. Confirmez avec O (ou Y) puis Entrée si on vous le demande.

    Sans terminal : sur beaucoup de distributions, un double-clic sur le .deb ouvre un installeur graphique (Logithèque, Installateur de paquets…).

  3. Lancez Forge Audio depuis le menu des applications (catégorie Son et vidéo / Multimédia) et connectez-vous, ou créez votre compte avec votre code d'invitation.

Installer le .rpm (Fedora, openSUSE)

  1. Ouvrez un terminal dans le dossier Téléchargements, comme pour le .deb, puis tapez : 
    sudo dnf install ./ForgeAudio-*-linux-x86_64.rpm

    Sur openSUSE : sudo zypper install ./ForgeAudio-*-linux-x86_64.rpm. Tapez votre mot de passe, confirmez avec o ou y. Sur Fedora, un double-clic sur le fichier ouvre aussi Logiciels (GNOME Software).

  2. Lancez Forge Audio depuis le menu des applications et connectez-vous.

Lancer l'AppImage

  1. Rendez le fichier exécutable : clic droit sur le fichier AppImage → Propriétés → onglet ou section Permissions → cochez Autoriser l'exécution du fichier comme un programme (selon le bureau : « Exécutable comme programme », « Est exécutable »).

    Ou dans un terminal ouvert dans le dossier :

    chmod +x ForgeAudio-*-linux-x86_64.AppImage
  2. Double-cliquez sur le fichier (ou tapez ./ForgeAudio-*-linux-x86_64.AppImage). Rangez-le d'abord où il restera, par exemple dans un dossier ~/Applications : c'est ce fichier qui se met à jour.

    Il ne démarre pas ? Les AppImage ont besoin de la bibliothèque FUSE 2, absente par défaut sur Ubuntu 22.04 et plus récent. Installez-la : sudo apt install libfuse2t64 (Ubuntu 24.04 et plus) ou sudo apt install libfuse2 (Ubuntu 22.04). Sinon, prenez simplement le .deb.

Mises à jour

AppImage, .deb et .rpm : automatiques. Forge Audio télécharge la nouvelle version en arrière-plan et l'installe quand vous le quittez, ou tout de suite avec Redémarrer dans la fenêtre « Mise à jour prête ». Pour un .deb ou un .rpm, le système peut demander votre mot de passe administrateur pendant l'installation.

L'archive .tar.gz, aussi publiée sur GitHub pour les utilisateurs avancés, ne se met pas à jour seule : un simple avis s'affiche.

Bon à savoir : fermer la fenêtre quitte Forge Audio. La lecture en arrière-plan s'active dans le menu de l'icône Forge Audio, si votre bureau affiche une zone de notification (sous GNOME, il faut une extension pour cela).

Désinstaller

  • .deb : sudo apt remove forge-audio-desktop
  • .rpm : sudo dnf remove forge-audio-desktop (openSUSE : sudo zypper remove forge-audio-desktop)
  • AppImage : supprimez le fichier.

Votre compte et vos playlists restent sur le serveur.
