Forge Audio sur Mac

Pour les Mac à puce Apple (M1 et suivantes) et les Mac Intel. Comptez cinq minutes. Forge Audio n'est pas signé par Apple : la première ouverture demande un passage par les Réglages Système, expliqué ci-dessous.

{{platforms}}

1. Quel Mac avez-vous ?

  1. Menu Pomme (la pomme en haut à gauche de l'écran) → À propos de ce Mac.

    Si la fenêtre affiche une ligne Puce (par exemple « Apple M2 »), prenez la version Apple Silicon.

    Si elle affiche une ligne Processeur avec « Intel », prenez la version Intel.

Apple Silicon

Puce M1, M2, M3, M4 ou plus récente.

Télécharger pour puce Apple 125 Mo

Intel

Mac avec processeur Intel.

Télécharger pour Intel 136 Mo

Version de bureau 0.26.2, fichiers .dmg hébergés sur GitHub. Sur un navigateur qui sait reconnaître la puce (Chrome, Edge, Brave), le bon bouton est mis en avant.

2. Installer

  1. Ouvrez le fichier .dmg téléchargé (dans le dossier Téléchargements), puis glissez l'icône Forge Audio sur le dossier Applications dans la fenêtre qui s'ouvre.

    Ensuite, éjectez le disque « Forge Audio » (bouton ⏏ dans la barre latérale du Finder). Le fichier .dmg peut être mis à la corbeille.

  2. Ouvrez Forge Audio depuis le dossier Applications (ou le Launchpad). macOS refuse une première fois : il ne peut pas vérifier l'application, car elle n'est pas notarisée par Apple.

    Cliquez sur Terminé. Surtout pas sur Placer dans la corbeille.

    Si le message dit que l'application est endommagée, passez directement à la section « Forge Audio est endommagé ».

  3. Menu Pomme (la pomme en haut à gauche de l'écran) → Réglages Système → Confidentialité et sécurité. Faites défiler jusqu'à la partie Sécurité : une ligne parle de Forge Audio. Cliquez sur Ouvrir quand même.

    Ce bouton n'apparaît que pendant environ une heure après votre tentative d'ouverture. Vous ne le voyez pas ? Refaites l'étape précédente, puis revenez ici.

  4. Confirmez : une dernière alerte s'affiche avec un bouton Ouvrir quand même (ou Ouvrir). Cliquez dessus, puis tapez le mot de passe de votre session Mac (celui qui sert à déverrouiller le Mac) et validez.

    C'est fini : macOS ne le demandera plus pour Forge Audio. L'application s'ouvre sur la page de connexion : Se connecter, ou Créer un compte avec votre code d'invitation.

macOS 14 Sonoma ou plus ancien ? C'est plus simple : dans le dossier Applications, faites un clic droit (ou Contrôle + clic) sur Forge Audio, choisissez Ouvrir, puis Ouvrir à nouveau dans l'alerte. Depuis macOS 15 Sequoia, ce raccourci ne marche plus : passez par les Réglages Système comme ci-dessus.

« Forge Audio est endommagé et ne peut pas être ouvert »

Ce message fait peur, mais l'application n'est pas abîmée. Le navigateur a posé sur le fichier une étiquette « téléchargé d'Internet » (la quarantaine), et macOS refuse alors d'ouvrir une application qui n'est pas signée par Apple. Une commande retire cette étiquette. Cliquez d'abord sur Annuler (jamais sur « Placer dans la corbeille »), puis :

  1. Vérifiez que Forge Audio est bien dans le dossier Applications (étape « Installer » ci-dessus). La commande vise cet emplacement.
  2. Ouvrez le Terminal : appuyez sur Cmd + Espace, tapez Terminal, puis Entrée. (Ou Finder → Applications → Utilitaires → Terminal.)
  3. Copiez cette commande, collez-la dans le Terminal (Cmd + V) et appuyez sur Entrée : 
    xattr -cr /Applications/Forge\ Audio.app

    En détail : xattr gère les étiquettes d'un fichier, -c les retire toutes, -r le fait aussi pour tout ce que contient l'application, et /Applications/Forge\ Audio.app est son emplacement (la barre oblique inversée devant l'espace fait partie du nom, ne la retirez pas).

    Si rien ne s'affiche, c'est réussi. Le Terminal ne demande pas de mot de passe pour cette commande.

  4. Rouvrez Forge Audio depuis Applications. Si macOS affiche encore l'alerte « n'a pas été ouvert », suivez les étapes 3 et 4 de l'installation (Réglages Système → Ouvrir quand même).

Ne lancez cette commande que pour une application que vous avez téléchargée vous-même depuis une source de confiance, comme ce site. Elle supprime une protection de macOS pour cette application précise, rien d'autre.

Mises à jour

Sur Mac : avis seulement. Sans signature Apple, une application ne peut pas se remplacer toute seule. Quand une nouvelle version sort, Forge Audio affiche une fenêtre avec un bouton Télécharger. Récupérez le nouveau .dmg, glissez Forge Audio dans Applications et choisissez Remplacer. Il faudra peut-être refaire « Ouvrir quand même » une fois.

Vos playlists et votre historique sont sur le serveur : remplacer l'application ne fait rien perdre.

Désinstaller

Ouvrez le dossier Applications et glissez Forge Audio dans la Corbeille (ou clic droit → Placer dans la corbeille), puis videz la Corbeille. Votre compte reste sur le serveur.
