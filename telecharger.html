Pourquoi mon système affiche-t-il un avertissement ? Forge Audio est un projet personnel : ses applications ne sont pas signées avec un certificat payant de Microsoft ou d'Apple, et l'application Android ne passe pas par le Play Store. Windows, macOS et Android préviennent donc qu'ils ne connaissent pas l'éditeur. Chaque guide montre exactement quoi faire. Le code des applications est public sur GitHub, et les fichiers sont ceux produits automatiquement à partir de ce code.

Après l'installation, il vous faut un compte : il se crée avec un code d'invitation. En savoir plus.
