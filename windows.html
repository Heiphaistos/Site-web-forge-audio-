Forge Audio sur Windows

Pour Windows 10 et Windows 11 (64 bits). Comptez cinq minutes. Windows va afficher un ou deux avertissements : c'est normal, et ce guide montre exactement où cliquer.

1. Choisir et télécharger

Recommandé

Installeur

S'installe comme un logiciel classique, crée un raccourci sur le bureau et se met à jour tout seul.

Télécharger l'installeur 112 Mo
Sans installation

Portable

Un seul fichier à lancer, par exemple depuis une clé USB. Il ne se met pas à jour seul : il vous prévient, et vous retéléchargez le fichier.

Télécharger la version portable 111 Mo

Version de bureau 0.12.2. Les fichiers sont hébergés sur GitHub, dans les publications du projet.

  1. Si le navigateur affiche un avertissement, conservez le fichier.

    Microsoft Edge peut indiquer que le fichier n'est pas couramment téléchargé. Ouvrez les Téléchargements (icône flèche en haut à droite), cliquez sur les trois points … à côté du fichier, puis Conserver. Si Edge insiste, cliquez sur Afficher plus puis Conserver quand même.

    Google Chrome peut aussi signaler le fichier dans sa liste des téléchargements : ouvrez-la (Ctrl + J) et choisissez l'option qui conserve le fichier.

    Pourquoi ? Ces navigateurs se méfient de tout programme encore peu téléchargé dans le monde. Forge Audio en fait partie.

  2. Ouvrez le fichier téléchargé : cliquez dessus dans la liste des téléchargements du navigateur, ou double-cliquez dessus dans le dossier Téléchargements de l'Explorateur de fichiers.
  3. Écran bleu « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires.

    C'est Microsoft Defender SmartScreen. Il s'affiche pour toute application qu'il ne connaît pas encore, surtout si elle n'est pas signée par un certificat payant. Sur Windows 11, le titre peut être « Windows a protégé votre PC ». Ne cliquez pas sur Ne pas exécuter : cela annule simplement.

  4. Cliquez sur Exécuter quand même.

    Le même écran affiche maintenant le nom du fichier et « Éditeur : Éditeur inconnu », avec un nouveau bouton. Windows ne le demandera plus pour ce fichier.

  5. Suivez l'assistant d'installation (installeur seulement).

    Il demande pour qui installer Forge Audio et dans quel dossier : les choix proposés conviennent. Cliquez sur Suivant, puis Installer, puis Terminer. Windows peut demander l'autorisation d'apporter des modifications : répondez Oui.

    La version portable, elle, s'ouvre directement : pas d'assistant.

  6. Lancez Forge Audio et connectez-vous.

    L'icône est sur le bureau et dans le menu Démarrer. L'application s'ouvre sur la page de connexion du serveur connect.forgeaudio.heiphaistos.org : onglet Se connecter si vous avez un compte, ou Créer un compte avec votre code d'invitation.

    Au tout premier lancement, l'application peut prendre quelques secondes de plus : elle prépare ses outils de lecture.

Si un antivirus bloque ou supprime le fichier

Un antivirus peut se méfier d'une application récente et non signée, sans qu'elle soit dangereuse. Vérifiez d'abord que vous avez bien téléchargé le fichier avec les boutons de cette page, qui mènent aux publications officielles du projet sur GitHub (github.com/Heiphaistos/Forge-audio-).

  • Microsoft Defender : ouvrez Sécurité Windows → Protection contre les virus et menaces → Historique de protection. Vous y voyez l'élément bloqué et pouvez choisir de l'autoriser si vous lui faites confiance.
  • Autre antivirus : regardez sa quarantaine ou son journal, restaurez le fichier et ajoutez une exception.
  • Dans le doute, ne forcez pas : écrivez-nous, ou utilisez le lecteur web qui ne demande aucune installation.

Mises à jour

Installeur : automatiques. Forge Audio vérifie les nouvelles versions, les télécharge en arrière-plan et les installe en silence quand vous fermez l'application. Une fenêtre « Mise à jour prête » propose aussi Redémarrer pour l'installer tout de suite, ou Plus tard.

Version portable : avis seulement. Elle ne peut pas se remplacer elle-même. Quand une version sort, une fenêtre vous prévient avec un bouton Télécharger : récupérez le nouveau fichier et supprimez l'ancien. Vos playlists sont sur le serveur, vous ne perdez rien.

Bon à savoir : fermer la fenêtre quitte Forge Audio. Pour que la musique continue fenêtre fermée, cochez la lecture en arrière-plan dans le menu de l'icône Forge Audio, près de l'horloge.

Désinstaller

  1. Windows 11 : Démarrer → Paramètres → Applications → Applications installées. Cherchez Forge Audio, cliquez sur … puis Désinstaller.
  2. Windows 10 : Démarrer → Paramètres → Applications → Applications et fonctionnalités, cliquez sur Forge Audio puis Désinstaller.
  3. Version portable : supprimez simplement le fichier.

Votre compte, vos playlists et votre historique restent sur le serveur.
